## Data Flow

1. User opens the application and lands on `SplashScreen` via `MainActivity`.
2. App checks authentication state. If unauthenticated, navigates to `SignInScreen` using Google Sign-In (Credential Manager).
3. Post sign-in, if the user hasn't completed onboarding, they are routed through the onboarding flow (`NavGraph` screens).
4. `OnboardingViewModel` retains state across screens, eventually saving the profile into `UserRepository` or directly to Firebase Firestore.
5. Upon completion, the user is navigated to `HomeScreen`.
